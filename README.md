# Python в ИИ-инженерии

Четыре учебных проекта Тимура Гиниятуллина в Школе 21.

| Проект | Что можно проверить |
|---|---|
| [Маршрутизатор обращений](request-router/) | Категория и приоритет для записей CSV или JSON |
| [Анализ журналов](json-logs-parser/) | Расход токенов, ошибки и задержка ответов |
| [HTTP-клиент](embedding-client/) | Повторы при временных ошибках тестового сервиса |
| [Подготовка документов](document-preprocessing/) | Очистка текста и сравнение способов деления на фрагменты |

## Запуск в PowerShell

Откройте терминал в корне репозитория и выполните команды по порядку.

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pytest -q
```

Команды для запуска каждой работы приведены в её папке.
