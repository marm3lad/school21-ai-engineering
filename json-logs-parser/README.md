# Анализ журналов запросов

Из папки проекта запустите `python AIE2.py`. Программа читает по одной JSON-записи на строку и выбирает запросы с расходом свыше 1000 токенов. Отчёт появится в `results/report.json`. На примере проходят две записи, суммарный расход составляет 2800 токенов, средняя и медианная задержки равны 110 мс.
