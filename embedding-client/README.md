# Клиент тестового сервиса

Клиент отправляет текст по HTTP, получает вектор и повторяет запросы при тайм-ауте и кодах 429, 500 и 503. Локальный сервер имитирует временные сбои и возвращает случайный вектор из 128 чисел.

Из папки проекта запустите `python mock_embedding_api.py`. Во втором терминале активируйте окружение, откройте ту же папку и выполните `python embedding_client.py`. Команда `python benchmark_retries.py` сравнивает три настройки повторов по времени и числу успешных запросов. Тесты клиента запускаются командой `python -m pytest -q` и используют имитацию ответов.
