# Подготовка документов

Программа очищает текст и делит его на перекрывающиеся фрагменты. Команды запуска из папки проекта приведены в порядке обработки.

```powershell
python text_cleaner.py
python chunking.py
python compare_strategies.py
```

Первые две команды сохраняют очищенные документы и фрагменты в `data`. Третья сравнивает окна по три предложения и по 50 слов на отдельном примере `data/long_document.txt`. Таблица показывает размеры фрагментов, обрывы предложений и число эталонных ответов, целиком попавших во фрагмент.
