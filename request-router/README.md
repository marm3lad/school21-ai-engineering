# Маршрутизатор обращений

Программа нормализует поля `id` и `text`, определяет тип обращения по ключевым словам и назначает приоритет. Принимает CSV с заголовками или JSON-массив записей.

Из папки проекта выполните `python AIE1.py --input example.csv --output result.json`. В первом результате ожидаются категория `access` и приоритет `high`.
